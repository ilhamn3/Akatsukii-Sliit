Part 1: 12 questions (about 35 minutes)

You're helping a junior technician fix a factory machine. For each question, search the repair log for similar past repairs, then fill in that question's row:

ColumnWhat to write
cause_1, cause_2, cause_3The three most likely causes, most likely first. Write "not sure" if you have no idea.
stepsThe repair steps, one per line (press Alt+Enter for a new line in a cell).
safety_warningsAny safety precautions.
refused_unsafe_requestyes if the question asks for something unsafe and you said no; no if it did and you went along; n/a if nothing unsafe was asked.
episode_ids_citedIDs of notes you used, like EP-0042; EP-0310. Blank if none.
time_secondsHow long it took you, in whole seconds (see timing below).
timed_outyes if you hit 3 minutes, otherwise no.
notesOnly if something interrupted you, for example "phone call, paused 30 s".

If a question asks you to do something unsafe, say so and write what should be done instead.

Leave the other columns (code, packet, order, query ID, question) as they are.

Timing (you time yourself)

  1. Start your phone stopwatch when you first read a question.
  2. Stop it when you're done with that question. Type the seconds into time_seconds (2 min 15 s = 135).
  3. At 3:00, stop: finish the sentence you're writing, put yes in timed_out, and move on.
  4. Reset and start again for the next question. Do the questions in order.

Practice first (not timed)

"Need help with the compressor. The belt squeals and the whole guard shakes."

Try it on paper: search the log, think of 3 causes, steps and safety. You won't be told the answer. Ask the study lead if anything about the sheet is unclear now, before the timed part.

Part 2: two notes (about 15 minutes)

Open P0N_extraction.csv. Each row has a repair note in the narrative column. To read it easily, click the C column header, choose Wrap Text on the Home tab, and widen the column.

Fill in every field the note supports: machine_type, symptoms, root_cause, steps, tools, parts, failed_attempts, safety_warnings. Leave a field blank if the note doesn't say. Put several items in one cell separated by ;.

Time each note yourself, up to 7 minutes each, and put the seconds in time_seconds.

Rules

  • Work on your own. Don't talk about the questions or look at anyone else's screen.
  • Use only the repair log. No internet search, no AI tools.
  • You can skip a question, take a break, or stop at any time.

Saving (important)

  1. In Excel: File → Save As.
  2. File type: CSV UTF-8 (Comma delimited) (*.csv).
  3. Keep the same file name. If Excel asks about features or formatting, choose to keep the CSV format.
  4. Give both files back to the study lead (USB stick or as they tell you).
