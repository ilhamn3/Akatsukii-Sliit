# Session materials

Generated by `python project/human_study/make_materials.py` from the frozen test set and
the episode narratives. Don't edit these by hand: rerun the script. See `../protocol.md`
for how to run a session.

| File | Give to participant? | Use |
|---|---|---|
| `repair_log.html` | Yes, open in a browser | All 400 notes, with a search box and machine filter. Narratives only, no answers. |
| `practice.md` | Read it to them | One dev-split question for the untimed practice. |
| `packet_A.csv` … `packet_E.csv` | Yes, one copy per person | Their 12 questions. Save a copy as `P01_packet_A.csv` (and so on) and fill it in. Tiers are not shown. |
| `extraction_sheet.csv` | Yes, one copy per person | Two notes to turn into structured fields. |
| `participants.csv` | No, the study lead keeps it | Code, packet, broad background. **No names.** |

Packet assignment: P01 and P06 get A, P02 and P07 get B, P03 gets C, P04 gets D, P05 gets E.

Completed sheets go in `project/human_study/results/`, named `P01_packet_A.csv` and `P01_extraction.csv`, with the filled `participants.csv` beside them. Then run `python project/human_study/build_grading.py` (see `../grading/README.md`). Signed consent forms
**never** go in the repository. Keep them in `project/human_study/private/`, which Git ignores.
